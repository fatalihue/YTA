# YTA

App desktop com frontend React + Tailwind 4.

## Interface

- **Antes de qualquer trabalho de interface, ler `.claude/skills/diretriz-visual/SKILL.md`.** Ela
  manda em tipografia, espaçamento, cor, componentes, movimento, copy e acessibilidade, e diz qual
  skill de design usar em cada passo. Em conflito, a diretriz vence as skills genéricas.
- As fundações (tokens em Tailwind 4) começam por `.claude/skills/diretriz-visual/tokens.css`.
- Armadilhas técnicas já conhecidas: `.claude/skills/diretriz-visual/licoes-tecnicas.md`.
- Decisões visuais tomadas no projeto vão para a seção 9 da diretriz, com data e motivo.
- A skill `impeccable` baixa um executável na primeira execução do seu lançador — pedir antes.
